# Raunak Saha — portfolio

Personal site for [Raunak Saha](https://github.com/raunaksahahere). Next.js 16 (App Router, Cache Components),
TypeScript, Tailwind CSS 4, Motion and Lucide.

## Develop

```bash
npm install
npm run dev        # http://localhost:3000
npm run lint
npm run build
```

## Where things live

| Path | What |
|---|---|
| `src/data/projects.ts` | The project catalog. Edit `featuredOrder` to change Selected Work; featured projects get `/projects/[slug]` case studies. |
| `src/data/toolbox.ts` | Technologies, grouped, with the projects each one appears in. |
| `src/data/site.ts` | Name, email, social links, nav. |
| `src/lib/github.ts` | Public GitHub data, cached hourly with `"use cache"`. Returns `null` on failure; the UI then says so instead of showing numbers. |
| `src/components/illustrations/` | Hand-built SVG illustrations (hero desk scene, Bit the robot). |
| `public/projects/` | Real screenshots and repo assets for project previews. |

Every project description comes from that project's repository. Live links are only included
for deployments that responded when the catalog was written.

## Deploy on Vercel

1. Import the repository in Vercel (framework preset: Next.js, no extra settings).
2. Optionally set `NEXT_PUBLIC_SITE_URL` (your custom domain) and `GITHUB_TOKEN` (no scopes; enables the contribution calendar).
3. Deploy.

`sitemap.xml`, `robots.txt`, the Open Graph image and the favicon are generated by the app.
